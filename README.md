# Command Creator

A skill for designing reusable Claude Code slash commands as clear, testable Markdown workflows.

## Capabilities

- Define a command's purpose, name, inputs, and outputs.
- Choose project, user, or plugin command locations.
- Write Markdown command instructions and supported YAML frontmatter.
- Handle arguments, file references, and tool permissions.
- Add validation, error handling, and safety boundaries.
- Review and test commands before use.

## Included references

- `references/patterns.md`
- `references/examples.md`
- `references/best-practices.md`

## Usage

Use when creating or improving a reusable slash command. Read the relevant reference files for patterns, examples, and quality checks. Confirm the installed Claude Code version before relying on version-sensitive command features.
